# TimSyS Platform Extraction

TimSyS owns domain-neutral execution and governance contracts. Applications own domain meaning, records, policies, and decisions.

## Platform-owned contracts

- supervised application identity and health;
- evidence and provenance envelopes;
- deterministic rule outcomes;
- insight lifecycle and action links;
- durable job identity, leasing and retry state;
- provider observations and freshness;
- audit events and human confirmation;
- UI and launcher lifecycle.

## Application-owned implementations

MemeCoin'Ed retains market providers, wallets, strategies, risk, paper/live execution and trading decisions. Dress'Ed retains garments, images, styling knowledge, ensembles, wardrobe planning and lifecycle decisions. Databases remain isolated by application.

Compatibility adapters may project domain records into TimSyS contracts. They must not weaken domain invariants or create a runtime dependency on Principal'Ed.
