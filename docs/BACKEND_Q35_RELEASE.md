Its independent executable, frozen science and model bytes, supervisor and versioned read-only contract live outside the desktop launcher's lifecycle. Research'Ed release 2026.11.06.3 is retained. Its authoritative source compiles to the same JavaScript as the installed package. The cumulative update feed carries forward its existing frontend asset rather than replacing or omitting it.
