# Architecture decisions

1. Dress'Ed is a new TimSyS application, not a fork of Principal'Ed or MemeCoin'Ed.
2. Generic TimSyS facilities are consumed through existing contracts.
3. Dress'Ed owns an isolated PostgreSQL persistence boundary.
4. Garment images remain local and private.
5. Visual analysis and recommendations are deterministic and versioned.
6. The local CV service is separated from outfit scoring by structured fingerprint contracts.
