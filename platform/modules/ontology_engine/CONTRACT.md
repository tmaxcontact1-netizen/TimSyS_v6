# Standards Ontology service contract

The Standards Ontology is a shared backend consumable built only from verified, active Standards Repository versions. Each node and relationship retains provenance back to a source statement and the deterministic algorithm version that created it.

The initial ELA rules extract explicit cognitive functions, concepts and source hierarchy. Query results are advisory candidates, never final alignments. Rebuilding creates a new version and supersedes the previous build without destroying its audit trail.

The ontology does not own standards, alter source statements, infer teacher intent or approve an assessment alignment. Interpretation beyond explicit rules must be separately identified as AI-assisted or sent for professional review.
